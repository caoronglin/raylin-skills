# 中文公文 / 报告 DOCX 交付

> 核心信条：**模板是基底，不是参考。** 从空白文档模仿格式 = 编号、样式、页眉页脚全丢。

---

## Phase 0：拿到模板后的第一步（🛑 STOP）

**用户给了模板 .docx，第一件事是精确解析它，不是开始写。**

```python
from docx import Document
d = Document(TEMPLATE_PATH)          # 以模板本体为基底

# 必须逐项核对并记录：
#   1. 所有 styles（样式名与层级）
#   2. numbering 定义（numId / abstractNumId）
#   3. sectPr（页面尺寸、页边距、页眉页脚）
#   4. 现有段落结构（标题层级怎么排的）
```

🛑 **禁止猜格式**。2026-08-10 的教训原文：*"先要模板 docx 精确解析而非猜格式"*。

---

## Phase 1：自动编号根因（已攻克）

**症状**：自己新建文档写多级编号，编号乱跳 / 重排 / 不连续。

**根因**：编号定义（`numbering.xml`）与样式表（`styles.xml`）都挂在模板里，重建文档时没继承。

**解法（实测有效）**：

```python
doc = Document(TEMPLATE)              # ① 以模板为基底
for el in list(doc.element.body):     # ② 清空 body
    doc.element.body.remove(el)
# ③ 关键：保留 sectPr / styles / numbering 不动
# ④ 再往里灌新内容 → 编号自动跟样式走
```

要点：**清 body，不清 sectPr/styles/numbering**。这三样是编号正确的前提。

## Phase 2：内容迭代（调研报告类）

实测有效的迭代节奏（2026-08-10 调研报告）：

| 轮次 | 字数 | 增加内容 |
|---|---|---|
| 1 | 5533 | 主体框架 |
| 2 | 7687 | 补充数据与论证 |
| 3 | 10389 | 附录问卷原稿 + 6 份访谈纪要 + 第五章对话实录 |

**做法**：每轮交付后主动列出"还能加什么"，让用户选，而不是一次写到底。

## Phase 3：配图批量筛选

场景：几百张照片/截图里挑几张配图。

**流程**（实测 334 张 → 挑 6 张）：

1. `PIL` 拼 **3×6 网格图**（每张缩略图上方加**编号红标**）
2. 把网格图送视觉模型评估（实测 SiliconFlow `Qwen3-VL-32B`/`8B`）
3. 按编号回报入选图片，再取原图

🛑 **不要逐张调用视觉模型**——334 张会烧光预算且慢。网格化是关键的省钱步骤。

## Phase 4：交付前检查清单（🔴 CHECKPOINT）

- [ ] 中文渲染正常（字体：`SourceHanSansSC` 或模板自带字体）

- [ ] 与模板对照：标题层级、字号、行距一致
- [ ] 数据/引文来源已标注（🛑 禁止编造文献）
